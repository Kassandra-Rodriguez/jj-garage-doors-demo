# JJ Garage Doors concept site

Spec demo for JJ Garage Doors Ltd. Co., El Paso, TX. Static HTML, CSS and JS, no build step.
Built 2026-10-02 from the concrete-diaz-demo structure with a new graphite and amber skin.

## The pitch
Their current site (jjgaragedoorsep.com, GoDaddy builder) has an SSL certificate that expired
2 Feb 2026, so browsers show a security warning, and it has no quote form. The only way to
reach them is to call. This demo puts a lead form in the hero and repeats the call to action
down the page and in the mobile bar.
